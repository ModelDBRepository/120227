# Multistability of clustered states in a globally inhibitory network

The MATLAB scripts posted below reproduce Figs. 6,7 and 9 of the manuscript:

| Lakshmi Chandrasekaran, Victor Matveev, Amitabha Bose (2009)
**Multistability of clustered states in a globally inhibitory network**
*Physica D: Nonlinear Phenomena*, **238**(3): 253-263.
[DOI](http://dx.doi.org/10.1016/j.physd.2008.10.008) |

Please place all files in the same directory before running the main simulation script **Fig6.m**, **Fig7.m**, **Fig9.m**

---

| Script | Description |
| --- | --- |
| [Fig6.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/Fig6.m) | This m-script reproduces Figure 6 of above manuscript |
| [Fig7.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/Fig7.m) | This m-script reproduces Figure 7 of above manuscript |
| [Fig9.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/Fig9.m) | This m-script reproduces Figure 9 of above manuscript |
| [FigParameters.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/FigParameters.m) | Parameter file for Figs. 6 and 7 |
| [FigParameters_bistable.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/FigParameters_bistable.m) | Parameter file for Fig. 9 |
| [existence_bistable.m](http://web.njit.edu/%7Ematveev/Scripts/ClusteredStates/existence_bistable.m) | Subroutine for Fig. 9 script |
